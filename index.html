Question 
            Angel places three points A, B, and C at the origin, and also gives you an array a of length n.

            You must perform exactly n operations. During the i-th operation, choose one of these points and increase or decrease one of its coordinates by 2^ai.
            In other words, if the chosen point has coordinates (x,y), then in the i-th operation you may move it to (x+2^ai,y), (x−2^ai,y), (x,y+2^ai), or (x,y−2^ai).

            elements of array a = a_1, a_2 ... a_n (0 <= a_i <= 24)

            input 1 = 0, 0
            input 2 = 0, 0, 1
            input 3 = 0, 1, 2, 2, 4, 0
            input 4 = 24, 24, 24, 0, 0, 0

            output 1 = 1
            output 2 = 4
            output 3 = 192
            output 4 = 562950054084608
Solution 
            Most equal disturbution of powers into 3 buckets. Later into 2.

            Sort pows -> [4, 2, 2, 1, 0, 0]
            translate pows -> [16, 4, 4, 2, 1, 1]
            Distirbute pows -> [16, 4, 4] -> [16, 6, 4] -> [16, 6, 5] -> [16, 6, 6]
            Disturbute pows to floor and height -> [16, 12]
            return 16 * 12 = 192
